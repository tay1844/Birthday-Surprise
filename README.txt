BIRTHDAY SURPRISE - READY TO PUBLISH

No photos or external music files are needed. The Happy Birthday melody is synthesized in JavaScript using Web Audio API.

1. Extract this ZIP.
2. Open https://app.netlify.com/drop
3. Drag the extracted Birthday-Surprise-Ready folder into the upload area (do not upload the ZIP).
4. Wait for deployment, then copy the public URL Netlify provides.

The visitor must tap "Play birthday music" because mobile browsers block autoplay.
To personalize, edit the wording in index.html.
